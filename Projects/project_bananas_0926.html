Abstract

01

Background: Forecasting time series is a common modelling problem across many domains. Although I have done lots of statistical and machine learning modelling in university, I have mostly focused on cross-sectional methodologies. To address this gap, this report is the first in a series of reports documenting me learning time series forecasting methodologies. This study will aim to revisit an old personal project with a more appropriate time series methodology.
Methods: The project aims to use a linear regression model to forecast weekly banana prices in the United Kingdom using publicly available data collected between 1995 to 2026. Models containing solely features derived from the response of interest (capturing season and trend) will be compared to models containing lagged features derived from the “Origin” variable.
Objectives: The three main objectives of this revisitation are to educate myself on appropriate time series methodologies, build a linear regression model to forecast the average weekly banana price and to post updates as I learn new content. This report aims to provide a description of the project dataset, outline the intended project and provide the first project post on my portfolio.
Deliverables: Interim deliverables will consist of each post related to the project with a final deliverable being a consolidated write-up summarising notable findings.
Value-add: The value-add of the project is three-fold. Firstly, I will have a real project dataset to work on rather than contrived example datasets. Secondly, I will have personal projects to start showcasing on my portfolio. Finally, the selected model will roll over to a new project where I will aim to deploy the model and assess its performance as new data is published throughout the remainder of the year.
Project timeline:: There is no clear timeline, however it is unlikely that this project will not be concluded before the end of 2026. Updates will likely be sporadic given that I am doing this as a personal project.
